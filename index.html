Publishing Workflow

从本地到公开链接

  1. 本地维护内容 把 HTML、PPT 或 PDF 放进 `content` 目录，并在 `script.js` 的 `articles` 数组里新增入口。
  2. 推送到 GitHub 仓库 把这个文件夹提交到你账号下的新仓库，例如 `knowledge-publishing-site`。
  3. 启用 GitHub Pages 进入仓库 Settings -> Pages，选择 `main` 分支和根目录发布。
  4. 获得访问链接 通常会是 `https://rongdugithub.github.io/仓库名/`。
