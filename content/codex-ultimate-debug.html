Codex Debug

Codex 终极 Debug 方法

作者：李猈

用于处理 Codex 登录、配置或组件加载异常时的重置流程。

适用场景

当 Codex 出现登录异常、账户状态混乱、配置文件疑似损坏、首次启动卡住或组件加载报错时，可以尝试这套重置流程。

重要提醒

这个方法会删除 Codex 的本地认证和配置文件。操作前请确认你能重新登录 OpenAI 账户。

文件名通常是 auth.json 和 config.toml。如果你看到的是大小写不同的文件名，以实际文件为准。

操作步骤

找到用户目录下的 .codex 文件夹

Windows 常见位置是 C:\Users\你的用户名\.codex。

删除认证和配置文件

删除 auth.json 和 config.toml。这一步会让 Codex 重新走登录和配置初始化。

重新打开 CMD

关闭旧的命令行窗口，重新打开一个新的 CMD 或 PowerShell。

重新登录 OpenAI 账户

启动 Codex 后按提示登录 OpenAI 账户，完成授权。

等待首次组件加载

首次加载组件可能会非常慢，这是正常现象。

输入 hi 并耐心等待

输入 hi 后，可能会先等到一个红色错误。不要立刻关闭，继续耐心等待，等 Codex 回复。

一句话总结

删除 .codex 里的本地登录与配置文件，然后重新登录，让 Codex 从干净状态重新初始化。
