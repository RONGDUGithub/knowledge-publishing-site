🔑 Kimi API 配置说明

Kimi 提供 OpenAI 兼容 API，可在 Kimi 开放平台创建自己的 API Key；是否有免费额度或活动额度，以平台控制台当前显示为准。

不要在网页、GitHub 仓库或群聊里公开粘贴自己的 API Key。推荐配合 CC SWITCH 使用，并把 Key 保存在本机环境变量或工具配置中。

API Key：在 Kimi 开放平台控制台创建
Base URL：https://api.moonshot.ai/v1
常用模型：kimi-k2、kimi-k2-0905-preview、moonshot-v1-8k、moonshot-v1-32k、moonshot-v1-128k
