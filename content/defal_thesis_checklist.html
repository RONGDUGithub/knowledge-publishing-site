第一章

开始写论文前的准备

确定投稿目标，建立论文框架，准备技术素材。

💡 投稿前须知
如果确定了要投的会议和期刊，请务必使用官网要求的模板。需要搞清楚是否双盲评审等道德规范规则。
🎯 首次写作建议
第一次写作的时候，请找一篇顶会论文进行全方位的模仿。学习其结构安排、段落组织、图表样式、公式排版等。

一、Introduction（第一章）

讲清楚研究背景和动机
分析现有方法的缺陷和不足
明确提出你能解决的痛点（pain points）
列出本文的 Contributions（贡献点，通常3-4条）
给出论文组织结构（第X章是什么工作）

二、Preliminary（第二章）

系统介绍先验知识和背景理论
定义必要的符号和术语（与全文统一）

三、技术章节框架（第三章）

3.1 系统框架图

绘制 System Framework / Technical Workflow 图
技术部分描述完成后，使用 GPT 5.4 thinking Xhigh 生成画图提示词
在 Nano-banana2 中生成多版本图片进行比对
使用 WPS 图片编辑器手动微调（检查字体、内容一致性）

3.2 问题定义

用符号化内容定义所有变量
用公式定义最后要解决的优化问题
全文章节符号定义保持统一，首次定义后沿用

四、技术方案命名

为每个原创技术起一个具体的缩写名称

五、形式化要求（必读）

不允许连续三大段纯文字说理！必须形式化处理。
关键名词转化为字母符号
关键步骤转化为数学公式
关键说理形式化为理论和证明（Lemma/Theorem/Proof）
参考：学术论文写作规范指南

六、模块化整理

使用 \subsubsection 或 \noindent\textbf{小节标题.} 分块
不同意思的段落进行可视化分割

七、技术小节写作结构

小节开头说明：a) 现有方法怎么做及不足；或 b) 直觉方法及问题；或 c) 之前工作，然后讲我要怎么做

八、工作量体现

调研最新的相关论文（近1-2年）
实验对比方法三个以上

九、Related Work

Related work 的 section 部分要认真对待，调研要充分（六页以下的论文可以不用添加）。
已完成充分的 Related Work 调研（六页以下论文可跳过）

十、参考文献

使用 BibTeX (.bib) 格式管理参考文献

内容自检1 - GPT语法检查

🤖 GPT检查指令
将内容分章节（section）输入 GPT-4.1，使用以下命令：
这是我的要投的计算机科学论文，请帮我检查：a. 前后不一致的地方，b. 有无语法错误，c. 是否有解释不清楚的，d. 是否有大段的文字需要修改

GPT使用注意事项

了解GPT长记忆有限，该命令可以反复输入
复制完大段内容后，再次检查：a) 内容意思是否被修改；b) 字母在LaTeX格式中是否正确（注意转义）
要求GPT输出 "LaTeX" 格式，方便直接复制
以段落为单位修改，改完后检查当前段落正确性，再进入下一段
已阅读并理解所有注意事项

第三章

形式审查

细致的格式、引用、一致性检查。

一、文献引用检测

🔍 检测引用幻觉
务必检查 \cite{} 中的文献是否存在以下问题
a) 检查文章是否真实存在
b) 检查文章题目是否正确（避免缩写错误）
c) 检查表述是否正确和相关（引用内容是否支持你的观点）

二、标号统一

所有 Section 使用 \label{sec:语义名} 编号
所有图表使用 \label{fig:语义名} / \label{tab:语义名} 编号
所有伪代码使用 \label{alg:语义名} 编号
调用时使用 \ref{}，实现自动编号，无需手动追踪"图1""表2"

三、引用完整性

所有图表、伪代码在正文中必须有引用（\ref{}）
所有定义、公理、定理必须有存在意义的表述（说明其作用和用途）

四、一致性检查

关键词、技术名称、字母表述全文统一，不能有多种表述
a) 字母贴近实际意义（如用户集合用U而非A）
b) 同一字母不重复表达两个不同实体
c) 上下标使用尽量简化
d) 最后人工检查前后字母一致性（GPT可能遗漏）

五、简洁性原则

未被引用的公式去掉编号（使用 \[ \] 或 equation*）

六、实验图表布局

实验图表要集中（如8张或16张）
放置在实验部分每一页的最顶端（使用 [t] 置顶参数）

七、标题格式

检查二、三级标题大小写统一
黑体标题统一使用 \noindent\textbf{This is a caption.}
黑色标题必须添加"."（句点）

八、数据集引用

数据集名称使用加粗（\textbf{DatasetName}）
必须添加数据来源：a) 使用 \footnote{www.example.com} 或 b) 作为参考文献引入

九、编译检查

编译PDF后全文搜索"[TODO]"，确保无遗漏
编译PDF后全文搜索"？"，确保无遗漏
编译PDF后全文搜索"XXX"，确保无占位符
